# 📊 online store sales Dashboard – Excel Data Analysis Project

This project showcases an **interactive Sales Dashboard created in Microsoft Excel** using **1200 rows of online store sales data**.  
The dashboard converts raw transactional data into **clear business insights** to help stakeholders understand sales performance, profitability, customer behavior, and marketing effectiveness.

## 📁 Dataset Information
- **Dataset Type:** Online Store Sales Data  
- **Total Records:** 1200 rows  
- **Key Columns:**
  - Order ID  
  - Date, Month, Year  
  - Customer ID  
  - Product  
  - Quantity  
  - Unit Price  
  - Payment Method  
  - Order Status  
  - Coupon Code  
  - Referral Source  
  - Total Price  

---

## ❓ Business Questions Answered
- Which products generate the highest profit?
- How do sales change month-wise and year-wise?
- Which coupon codes perform best?
- What payment method is most preferred by customers?
- Which order status impacts revenue the most?
- Which referral source drives maximum sales?
- What is the relationship between order quantity and sales value?

- Order Status Analysis  
- Referral Source Performance  

---

## ⚙️ Process
1. **Data Cleaning**
   - Removed duplicate records
   - Standardized date, month, and year formats
   - Checked missing and inconsistent values

2. **Data Preparation**
   - Created calculated fields (Total Price, Profit)
   - Categorized products and order status

3. **Data Analysis**
   - Used Pivot Tables for aggregation
   - Calculated KPIs
   - Analyzed trends and comparisons

4. **Dashboard Design**
   - Added interactive slicers (Product, Month, Year, Payment Method, Coupon Code)
   - Designed KPI cards
   - Used consistent color themes and layouts

---

## 📊 Dashboard Features
- Fully interactive Excel dashboard
- Dynamic filtering using slicers
- KPI cards for quick insights
- Bar charts, line charts, donut charts, and pie charts
- Product, time-based, and customer-focused analysis

## 💡 Project Insights
- Some products consistently outperform others in profit
- Sales peak during mid-year months
- Coupon codes significantly influence order volume
- Online and card payments dominate transactions
- Email and Instagram are strong referral sources
- Returns and cancellations impact total realized sales
